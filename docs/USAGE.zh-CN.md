# SBW Controls 使用说明

**Flight control schemes & BF-style dynamic third-person camera addon for Superb Warfare**

- 模组名：**SBW Controls**
- mod id：`sbwcontrol`
- 版本：1.1.0
- 作者：sakasiyhaha
- 适用：Minecraft **1.20.1** / Forge **47.3.0** / Java **17**
- 前置：Superb Warfare **0.8.9.2**、Kotlin for Forge **4.12.0**
- 许可证：GPL-3.0（非官方附属，非卓越前线官方作品）

---

## 1. 这个模组解决什么问题

卓越前线本身有一套飞行操控和载具相机，但默认的固定翼操控更接近“原版飞行”，第三人称相机也偏刚性：

- 想用鼠标滚转、A/D 偏航，像“翻滚鸟”一样飞；
- 想让第三人称镜头在转弯、压坡度、加减速时有滞后/惯性，更像战地/三角洲那种动态瞄准相机；
- 想让第一人称和右键瞄准放大使用独立、稳定的参数，而不是套用第三人称的甩动；
- 想让每种参数都能在游戏内设置、TOML 或按键里调整。

SBW Controls 就是在不修改卓越前线源码、不装 Mixin 的前提下，通过服务端写入卓越前线公开输入字段 + 客户端相机事件实现的附属。

## 2. 功能总览

### 2.1 三种控制流派 + 自定义

| 流派 | 固定翼 | 直升机 | 说明 |
|---|---|---|---|
| **偏航鸟（YAW_BIRD）** | 原版 | 原版 | 不接管，保持卓越前线默认 |
| **翻滚鸟（ROLL_BIRD）** | 鼠标左右 = 滚转，A/D = 偏航，鼠标上下 = 俯仰 | 同左 | 默认方案，推荐先试这个 |
| **偏滚鸟（ROLL_YAW_HYBRID）** | 鼠标左右同时按比例参与滚转和偏航 | 同左 | 混合手感，适合既想滚转又想偏航的玩家 |
| **自定义（CUSTOM）** | 俯仰/滚转/偏航分别选择鼠标X、鼠标Y或按键对 | 同左 | 三轴完全自定义 |

- **A/D 偏航**是通过服务端额外直接偏航率实现的（默认约 30°/s + 引擎原生的少量偏航），不会只依赖引擎那个被 `rotSpeed` 钳制到约 6°/s 的偏航项。
- 翻滚鸟下，A/D 不会再额外触发卓越前线的滚转输入（已做按键压制）。
- 自定义方案的“俯仰/滚转/偏航源”只在方案为 CUSTOM 时可编辑，其他时候灰显。

### 2.2 B 键：切换当前载具流派

**骑乘固定翼/直升机时按 B**：

- 固定翼：循环切换固定翼默认流派
- 直升机：循环切换直升机默认流派
- **B 键和设置页读写的是同一组配置**：
  - 按 B 改了，设置页打开会显示新值；
  - 设置页改了下拉，下一次按 B 从新值继续循环。
- **不骑载具按 B**：只提示“请先骑乘固定翼/直升机”，不会改任何配置。
- **骑坦克/汽车/船等其他载具按 B**：提示“B 仅对固定翼/直升机有效”，不会改配置。

> 如果你完全不用 B 键：直接在设置页的“控制”页选“固定翼默认流派 / 直升机默认流派”即可，效果与 B 键完全一致。

### 2.3 动态第三人称相机

所有参数都在设置页“相机”分类里，分三个子页：

**基础**

| 参数 | 默认 | 作用 |
|---|---|---|
| 动态相机 | 开 | 总开关；关闭后完全使用卓越前线相机 |
| 相机预设 | 战地风 | BATTLEFIELD / DELTA / WARTHUNDER / VANILLA / CUSTOM，预设是参数的缩放风格 |
| 偏航平滑 | 0.10s | 偏航方向镜头追赶速度 |
| 俯仰平滑 | 0.08s | 俯仰方向镜头追赶速度 |
| 转向滞后 | 0.22s | 相机偏移 = 角速度(°/s) × 该秒数；往左偏航时镜头往右甩 |
| 速度 FOV | 0.10 | 速度越快 FOV 越大 |
| 动态距离 | 0.5 | 速度越快相机稍微后拉 |
| 瞄准缩放 | 0.35 | 右键瞄准时动态幅度缩放 |
| 相机滚转跟随比例 | 1.0 | 1.0 = 完全跟随机体滚转；0 = 镜头保持水平 |
| 横向居中 | 1.0 | 把卓越前线部分载具的左侧机位拉回中线；1 = 完全居中 |

**动态**

| 参数 | 默认 | 作用 |
|---|---|---|
| 反转转向滞后（左右） | 关 | 左右镜头甩动方向反向 |
| 反转上下转向滞后 | 关 | 上下镜头甩动方向反向 |
| 滚转惯性 | 0.10s | 压坡度/改出时镜头慢半拍；0 = 刚性跟随 |
| 位置弹簧 | 0.08s | 相机机位绕机身滞后摆动，而不是只转视角 |
| 自适应阻尼 | 1.5 | 机动越猛（偏航/滚转速度越高），滞后时间越短，越跟手；0 = 固定阻尼 |
| 弹簧阻尼比 | 0.90 | 1=临界阻尼最稳；<1 更有弹性/轻微回弹；>1 更硬更快停 |
| 角速度平滑 | 0.10s | 鼠标输入的低通时间；越大越不容易“瞬间弹一下” |
| 转向阈值软化 | 1.0 | 接近 ±12°/±8° 偏移极限时 tanh 软饱和减速；0=旧硬钳制 |

**第一人称 / 准星**

| 参数 | 默认 | 作用 |
|---|---|---|
| 第一人称动态 | 关 | 关闭时，第一人称和右键瞄准放大完全使用卓越前线原版相机；打开后才使用下面的 FP 参数 |
| FP 偏航/俯仰平滑 | 0.03s | 第一人称轻微平滑 |
| FP 转向滞后/滚转惯性/位置弹簧 | 0 | 第一人称默认不甩、不滚、不弹簧 |
| FP 自适应增益 | 0 | 第一人称默认固定阻尼 |
| 机头/炮口标记 | 关 | 在投影的炮口/机头方向画一个小标记（调试/瞄准辅助） |
| 替换第三人称准星 | 关 | 隐藏卓越前线第三人称载具准星，改在投影弹道点画十字+外圈；第一人称/右键放大仍用卓越前线自己的准星 |

相机实现要点：

- 转向滞后、滚转惯性、位置弹簧使用**固定 120Hz 子步长的物理弹簧**（速度跨帧保留），不是每帧硬跳；阻尼比 0.90 时接近临界阻尼；
- 转向偏移达到 ±12°/±8° 附近时使用 tanh **软饱和减速**，不会撞到硬阈值突然停住；
- 相机滚转目标在 ±180° 处做连续角展开，**完全倒置后也能平滑滚回正位**；
- 角速度取 tick 级角度差并低通，减少帧率波动造成的抖动；
- 第一人称/右键瞄准放大使用独立参数，不套用第三人称动态。

### 2.4 设置界面

**Mods → SBW Controls → Config**，单窗口 5 个分类：

| 分类 | 内容 |
|---|---|
| **控制** | 固定翼默认流派、直升机默认流派、自定义三轴来源；其他载具只读提示 |
| **相机** | 基础 / 动态 / 第一人称·准星 三个子页 |
| **操作** | 输入模型（速率/虚拟摇杆）、鼠标灵敏度/平滑/死区、摇杆回中/增益、三轴增益、四个反转、偏滚耦合、打开原版按键设置、恢复默认按键 |
| **服务端** | A/D 偏航率、yaw/roll/pitch 增益、输入超时、允许方案、应用载具类型、日志（仅单机可编辑） |
| **诊断** | 调试 HUD、遥测开关、遥测采样间隔 |

每页底部有 **恢复本页默认**。相机页按当前子页恢复；控制页恢复不会清空其他内容。

### 2.5 9 个快捷键（全部在原版按键设置里）

**选项 → 控制 → 按键绑定 → 卓越前线·操控附属**

| 默认按键 | 功能 |
|---|---|
| A / D | A/D 偏航左/右 |
| Q / E | Q/E 滚转左/右（自定义/按键轴时使用） |
| 未绑定 | 自定义抬头 / 自定义低头（仅 CUSTOM + 按键源） |
| B | 切换当前载具流派 |
| 未绑定 | 切换动态相机 |
| 未绑定 | 打开操控附属设置 |

操作页有“打开原版按键设置”和“恢复默认按键（只重置这 9 个）”。

## 3. 安装

### 3.1 单装 mod

1. Minecraft 1.20.1 + Forge 47.3.0 + Java 17；
2. `mods/` 放入：
   - `sbwcontrol-1.1.0.jar`
   - `superbwarfare-0.8.9.2-all.jar`
   - `kotlinforforge-4.12.0-all.jar`
3. 启动即可。

> 卓越前线的 GeckoLib / Cloth Config / Curios / Flywheel / Ponder / SimpleBedrockModel 等前置已 JarJar 内嵌在 `superbwarfare-0.8.9.2-all.jar` 中，不需要额外装。

### 3.2 用整合包

- Prism Launcher / MultiMC：直接导入 `SBW-Controls-Pack-1.1.0` 文件夹或 zip；
- 其他启动器：建一个 1.20.1 + Forge 47.3.0 实例，把 `mods/`、`config/`、`defaultconfigs/` 复制进去。

## 4. 快速上手

1. 进游戏，坐进一架固定翼或直升机；
2. 默认方案是**翻滚鸟**：鼠标左右滚转、A/D 偏航、鼠标上下俯仰；
3. 按 **B** 可以在偏航鸟/翻滚鸟/偏滚鸟/自定义之间循环；
4. 想调手感：**Mods → SBW Controls → Config → 相机**；
5. 想改按键：**选项 → 控制 → 按键绑定 → 卓越前线·操控附属**；
6. 右键瞄准时进入卓越前线的第一人称放大：默认使用原版相机；想加一点第一人称平滑，打开“第一人称动态”并调 FP 参数。

## 5. 参数怎么调（调参地图）

### 5.1 觉得镜头“太死/太粘”

- 增大 **转向滞后**（0.22 → 0.3~0.4）
- 增大 **滚转惯性**（0.10 → 0.15~0.2）
- 增大 **位置弹簧**（0.08 → 0.12~0.18）
- 增大 **自适应阻尼**（1.5 → 2~3），让机动时更跟手
- 降低 **弹簧阻尼比**（0.90 → 0.82~0.88），增加一点回弹
- 增大 **角速度平滑**（0.10 → 0.12~0.15），让起手更软
- 保持 **转向阈值软化** 为 1.0

### 5.2 觉得镜头“太甩/晕”

- 减小 **转向滞后**（0.22 → 0.12~0.18）
- 减小 **滚转惯性**（0.10 → 0.05）
- 减小 **位置弹簧**（0.08 → 0.04）
- 把 **相机滚转跟随比例** 降到 0.7 或更低
- 提高 **弹簧阻尼比**（0.95~1.05），减少回弹
- 降低 **角速度平滑**（0.08~0.10），减少拖尾

### 5.3 左右/上下方向反了

- 左右反：勾 **反转转向滞后（左右）**
- 上下反：勾 **反转上下转向滞后**

### 5.4 右键瞄准时镜头还在甩

- 确认 **第一人称动态** 是关闭状态（默认关闭时右键放大完全原版）；
- 如果打开了，把 FP 的 **转向滞后/滚转惯性/位置弹簧** 保持 0，只留 0.03 左右的 FP 平滑。

### 5.5 阈值附近仍然突兀

- 保持 **转向阈值软化** 为 1.0；把 **转向滞后** 适当增大（0.22 → 0.28~0.36），让目标值本身更慢到达阈值；
- 如果只是最大偏移量变小，可增大转向滞后或把软化为 0.85~0.95 折中。

### 5.5 帧率低导致镜头顿

动态相机是每帧计算，低 FPS 下再好的平滑也只能每秒更新几次。先确认 F3 正常 FPS；如果长期低于 30，优先查光影/其他 mod/后台程序，而不是继续加参数。

## 6. 配置文件

| 文件 | 路径 | 内容 |
|---|---|---|
| 客户端 | `config/sbwcontrol-client.toml` | 控制流派、相机、输入、遥测、按键以外的全部客户端参数 |
| 单机服务端 | `saves/<存档名>/serverconfig/sbwcontrol-server.toml` | A/D 偏航率、三轴增益、输入超时、允许方案、应用载具类型 |

- 设置页修改会立即写入 config，关闭界面时保存；
- 手改 TOML 后重启游戏 / 重进存档生效；
- 想恢复全默认：删除 `config/sbwcontrol-client.toml` 后重启，或使用设置页的“恢复本页默认”。

## 7. 命令

### 客户端 `/sbwctl`

```
/sbwctl status                  # 当前方案/输入/相机状态
/sbwctl selftest                # 客户端按键/通道/服务端支持自检
/sbwctl scheme aircraft <方案>  # 直接设置固定翼默认流派
/sbwctl scheme helicopter <方案>
/sbwctl camera on|off|status
/sbwctl camera delta            # 应用“三角洲风”预设
/sbwctl camera turnlag <0~0.6>
/sbwctl camera rolllag <秒>
/sbwctl camera rollratio <0~1.5>
/sbwctl camera lateral <0~1>
/sbwctl camera adaptive <0~5>
/sbwctl camera poslag <秒>
/sbwctl camera ads <0~1>
/sbwctl debug on|off
/sbwctl telemetry on|off|status
```

### 服务端 `/sbwctlserver`（需要 OP 等级 2）

```
/sbwctlserver status
/sbwctlserver scale yaw|roll|pitch <值>
/sbwctlserver yawrate <0~180>
/sbwctlserver timeout <tick>
/sbwctlserver allow ROLL_BIRD|ROLL_YAW_HYBRID|CUSTOM true|false
```

服务端还可以直接在 `serverconfig/sbwcontrol-server.toml` 里改。

## 8. 联机说明

- **服务端装了本附属**：客户端可以选择方案，服务端按照允许列表和通道增益应用；A/D 偏航等效果由服务端写回卓越前线载具。
- **服务端没装本附属**：客户端自动降级：
  - 控制流派切换禁用，只保留原版方案；
  - 动态相机、按键、客户端参数仍然可用；
  - 客户端 HUD 会提示“服务器未安装操控附属”。
- **联机时服务端有最终裁决权**：服务端不允许的方案，客户端选了也会被忽略并提示。

## 9. 兼容与限制

- 仅 Forge 1.20.1；不支持 Fabric。
- 只接管**固定翼**和**直升机**；坦克、汽车、船等其他载具保持卓越前线原版（B 也不会改配置）。
- 只对**第一乘客**生效；乘客位不接管。
- 遇到以下情况不接管，交还原版：
  - 盘旋自动驾驶
  - 残骸（isWreck）
  - TOM6 特殊引擎
  - 卓越前线自由视角
- 依赖卓越前线 0.8.9.2 的公开字段/相机方法；卓越前线大版本更新可能需重新适配。版本探测失败时会禁用相关功能，而不是崩溃。
- 第一人称/右键瞄准放大使用独立参数；默认 `first_person=false` 时完全原版。

## 10. 常见问题

**Q：按 B 没反应？**  
A：确认你骑的是固定翼或直升机，且是驾驶位；坦克/汽车按 B 不会改配置。服务端没装本附属时，方案切换会被禁用。

**Q：相机没变化？**  
A：检查“动态相机”是否开启、预设是否 VANILLA、是否在第一人称/右键放大（第一人称默认不叠加第三人称动态）。

**Q：A/D 不偏航？**  
A：确认方案是翻滚鸟/偏滚鸟/自定义；偏航鸟是原版。确认服务端允许方案；单机可看“服务端参数”页的 A/D 偏航率。

**Q：按键冲突/按了没效果？**  
A：到原版按键设置里检查 9 个按键是否被其他 mod 占用；A/D 与卓越前线原生载具键同名，本附属在方案激活时会压制其滚转含义。

**Q：画面滚转太晕？**  
A：降低“相机滚转跟随比例”，或增大“滚转惯性”。

**Q：倒置后镜头回不了正？**  
A：1.1.0 已修复 ±180° 滚转目标突变问题；如果仍出现，先把 `camera.roll_ratio` 设为 0 对比，并反馈日志。

**Q：整合包启动失败？**  
A：确认 Java 17、Forge 47.3.0；确认 `mods/` 只有整合包自带 3 个 mod（不要重复放不同版本）；看 `logs/latest.log`。
